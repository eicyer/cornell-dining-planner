# Migrated off the original Next.js/Supabase scaffold to FastAPI + React Native

An earlier session had scaffolded this project as Next.js 15 + Supabase + Nutritionix, documented in a `CLAUDE.md` that had the LLM (Claude) generate meal combinations directly rather than a deterministic optimizer. Only the `create-next-app` boilerplate commit ever landed in git — the actual app code (API routes, Supabase schema, suggestion/nutrition logic) was uncommitted and never run as working software.

Decision: standardize on FastAPI (backend) + React Native/Expo with react-native-web (frontend, covers iOS + desktop-as-web from one codebase), per [[0001-nutrition-data-source]] through [[0005-eatery-scope]]. The old Next.js/Supabase/Nutritionix code and its `CLAUDE.md` are preserved untouched in `_archive-nextjs/` for reference, not deleted — but they are not the direction going forward. `CONTEXT.md` + `docs/adr/` replace `CLAUDE.md` as the project's source of truth. `.env.local` (Supabase, Anthropic, USDA, Nutritionix, cron secret keys) was kept in place at the project root since some keys (Anthropic, USDA) still apply; unused ones can be pruned later once the FastAPI app's actual env needs are known.
